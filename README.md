# ✈️ Flight Delay Prediction System

## 📌 Project Overview
This project predicts flight delays using historical flight data from SpiceJet operating between Pune International Airport and Delhi Airport. It analyzes past 15 days of flight records and uses machine learning to forecast delays and compare scheduled vs actual timings.

## 🎯 Objective
- Predict flight departure and arrival delays
- Analyze historical flight performance
- Visualize scheduled vs actual timings
- Help improve operational planning

## 📊 Dataset
- Source: Manually created/collected flight records
- Duration: 21st May – 4th June
- Route: Pune → Delhi
- Airline: SpiceJet
- Features:
  - Date
  - Scheduled Departure/Arrival
  - Actual Departure/Arrival
  - Delay (calculated)

## 🧠 Model Used
- Data preprocessing with Pandas
- Feature engineering (time conversion, delay calculation)
- Machine Learning model (Linear Regression / Random Forest can be used)

## 📈 Features
- Predict future flight delays
- Graph comparison: Scheduled vs Actual timings
- Tabular output for flight status
- Forecast for specific date (e.g., 17th June)

## 📉 Visualizations
- Line chart for delay trends
- Bar graph for comparison of scheduled vs actual times
- Table view for predictions
